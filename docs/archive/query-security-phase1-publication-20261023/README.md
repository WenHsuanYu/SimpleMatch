# Query Security Phase 1 publication snapshot

This archive preserves two original read-back records from the
2026-10-23 publication of Query Security Phase 1 Issues #188–#194:

- `published-issues.json` records the original issue identifiers,
  dependencies and ticket-body SHA-256 digests.
- `publication-verification.json` records the publication-time issue
  states, labels, dependencies and verification result.

Both files are byte-for-byte copies of the original files in
`.scratch/query-security-phase1/`. They are **historical snapshots**,
not current issue states, implementation approval, or security test
results. The seven local ticket drafts and publication README were
retired after the GitHub issues were completed. Refer to the GitHub
issues for their accepted requirements and completion evidence:
