target operating rules from repository execution plans, phase gates, task
tracking, and certification evidence.

- [Database architecture](database-architecture.md) — database topology and

- [Configuration](configuration.md) — configuration ownership and boundaries.
- [Development environment](development-environment.md) — local toolchain,
  repository layout, and build expectations.
- [Deployment](deployment.md) — local composition, Kubernetes deployment, and
  service discovery.
- [Observability](observability.md) — traces, logs, metrics, dashboards, and
  alerts.
- [Testing](testing.md) — layered verification and certification posture.
- [Troubleshooting](troubleshooting.md) — first diagnostic checks for common
  operating failures.
